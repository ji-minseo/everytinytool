Questions, bugs or tool ideas?

Every Tiny Tool is an independent project. If you find a broken tool, confusing result or privacy issue, feedback is useful.

Email us

For general questions, privacy requests, bug reports or suggestions, email us directly. No GitHub account is needed.

info.everytinytool@gmail.com ↗

Public bug reports

For issues that can be discussed publicly, you may also use our GitHub issue tracker. Please avoid posting private information or file contents.

Open GitHub Issues

When reporting a tool problem

It helps to include the tool name, what you expected, what happened instead, and the browser or device you were using. Never post passwords, private files or sensitive information in a public issue. For privacy questions, use email instead.
