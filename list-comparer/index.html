The details

What this comparison actually checks

Use this when you need to see what changed between two versions of a list, such as a guest list, product catalog or an inventory export.

Three useful groups

Only in A shows items missing from the second list. In both shows matching entries, and Only in B shows additions. You can copy each group individually.

How matching works

Each entry is a single line. Leading and trailing spaces are ignored. Identical entries within one list count once. The tool keeps the first spelling it finds; by default, “Apple” and “apple” match.

Example: compare stock lists

List A contains Apple, Banana, Cherry. List B contains Banana, Mango, Cherry. The shared items are Banana and Cherry, only A contains Apple, and only B contains Mango.

Limitations

Comparison is exact after trimming and optional case normalization: it will not guess that “NYC” means “New York City.” One entry should occupy one line. Each input supports up to 50,000 characters or 5,000 non-empty lines.

Common questions

Does the order of items matter?

No. Order does not affect whether two entries match. Results preserve their first-seen order within List A or List B so you can trace where items came from.

Can I compare two lists with duplicates?

Yes. Repeated entries are removed within each list before comparison. If you need to preserve every repeated instance, use the list cleaner on the homepage and switch off duplicate removal.

Are my lists uploaded?

No. This tool compares text in your browser and does not send your pasted entries to an Every Tiny Tool server. Avoid entering sensitive information into public tools regardless.
