    How to use Tiny Workspace

    Begin with one entry on each line. Choose a sequence from ten available transformations. Each step uses the previous step's output, so filtering before sorting gives a different preview path from sorting before filtering. Move steps with the arrows, remove any you don't need, and click a history chip to preview that stage.

    Use Compare with another list to see only-in-result, shared and only-in-reference entries. Comparison ignores duplicates and blank lines in each set; matching is case-insensitive by default. For export, select TXT, CSV (one column named item) or JSON (an array of strings).

    Important limits

    Text is processed locally. Each input supports up to 200,000 characters and 10,000 lines. This workspace is designed for line-separated items, not complex spreadsheet tables: commas remain part of a line and quoted CSV columns are not parsed. For structured multi-column spreadsheets, use a dedicated spreadsheet app.

    Frequently asked questions

    What's different from a regular duplicate remover?

    A duplicate remover performs one action. Tiny Workspace lets you combine cleanup, keyword filtering, find and replace, sorting and prefix or suffix changes into one ordered sequence, previewing each stage and saving the steps for reuse.

    Is the order of operations important?

    Yes. For example, trimming before duplicate removal makes " Apple " and "Apple" identical, while removing duplicates first may keep the different whitespace versions. Move steps to control exactly what happens.

    Are my lists uploaded or stored?

    No file upload or external API is used to process your text. Your list is held in the current browser page only. If you save a workflow, only the step configuration and named settings are kept in your browser's local storage.

    Can I export the result as Excel or CSV?

    You can download CSV, TXT or JSON. CSV is a one-column export that can be opened in Excel or Google Sheets; it isn't an .xlsx workbook.

    Can I compare lists before or after cleaning?

    Comparison uses the final processed output against your unmodified reference list. If you want to compare raw lines, remove all transformation steps first.
