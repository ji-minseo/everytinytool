What Your Photos and PDFs Reveal: How to Check Hidden Metadata

By Every Tiny Tool Editorial · Published October 19, 2026

Understand and inspect hidden photo and PDF properties, including timestamps, author names, location and editing software.

Try the tool: Inspect file metadata ↗

What metadata is

Metadata describes the file beyond the immediately visible content. It may identify the creation date, software, device, author or location. What is present depends on the format and export path.

Photo metadata to look for

JPEG images may carry EXIF fields such as camera model, exposure, date taken, orientation and GPS coordinates. XMP and IPTC can contain descriptions, creator or copyright fields. A screenshot typically differs from a camera original.

PDF properties to check

A PDF may contain author, title, subject, keywords, creation date, modification date, producer and creator application. Some PDFs also contain attachments, annotations, form values or other embedded content. Basic metadata inspection does not replace a full document privacy review.

Inspect a sample safely

Choose a non-sensitive test file, open Metadata Inspector and review the recognized fields. Compare the displayed metadata with the file's visible content. If your tool does not recognize a property, that does not prove it is absent.

Decide what to retain

Author and creation metadata can be helpful for archives and version tracking. For public distribution, remove unnecessary identifying fields through a tool that supports the specific file type. Keep the original and verify any re-export.

Limitations and verification

Some attributes may be stored outside standard EXIF, XMP or PDF document-info dictionaries. A cleaner may not remove embedded attachments, visible annotations, revision traces or all proprietary fields. Confirm exactly what the output contains before sharing.

Frequently asked questions

Are photo and PDF metadata the same?

No. Different formats store different categories of properties.

If an inspector shows no fields, is the file clean?

Not necessarily; the inspector may not support every metadata type.

Can PDF author information be removed?

Many PDF editors offer a way to change document properties, but verify the exported file and other embedded content.
